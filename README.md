\# Breach Exposure Checker



\## Overview



Breach Exposure Checker is a cybersecurity-based full stack web application that detects whether an email or username appears in known data breaches.



The project also analyzes password strength, scans suspicious URLs, generates AI-based security summaries, and provides downloadable security reports.



\---



\# Features



\## 1. Email Breach Checker

Checks whether an email exists in known breach datasets.



\## 2. Username Breach Checker

Detects exposed usernames from leaked databases.



\## 3. Risk Level Analysis

Analyzes exposure severity and calculates risk level.



\## 4. Breach Count Display

Displays total breaches detected.



\## 5. Leaked Data Detection

Shows exposed data types:

\- Emails

\- Passwords

\- Phone Numbers

\- IP Addresses



\## 6. Password Strength Checker

Analyzes password security level.



\## 7. Suspicious URL Scanner

Detects phishing indicators and dangerous URLs.



\## 8. AI Security Summary

Generates cybersecurity recommendations.



\## 9. Export Security Report

Downloads security analysis report.



\## 10. Security Dashboard

Displays live security statistics and threat status.
